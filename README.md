# Organisation d'une maraude solidaire

## Membres du groupe

- WASEL Yassine
- ALLOUNE Abdelwadoud

## Objectif du projet

Ce projet a pour objectif d'organiser une maraude solidaire afin de distribuer des repas, des boissons et des produits d'hygiène aux personnes dans le besoin.

## Organisation Kanban

Le projet est organisé avec un tableau Kanban composé de trois colonnes :

- À faire
- En cours
- Terminé

La limite WIP de la colonne En cours est fixée à 3 tâches maximum.

## Tâches principales

- Définir la date et le lieu de la maraude
- Lister les besoins matériels
- Acheter les denrées alimentaires
- Préparer les sacs de distribution
- Répartir les rôles entre les membres
- Préparer l'itinéraire
- Réaliser la maraude
- Faire un bilan après la maraude
